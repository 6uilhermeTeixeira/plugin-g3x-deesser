## Observações úteis

- A hierarquia privilegia modo, frequência e monitoração à esquerda.
- Threshold, atividade do detector e atenuação ocupam a região central.
- A saída estéreo é apresentada separadamente à direita.
- O fluxo reduz decisões a escolher a região e ajustar o nível de atuação.
- A identidade visual do G3X deverá se afastar deliberadamente desta aparência.
